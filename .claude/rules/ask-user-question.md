ユーザーに質問するとき（次に進めてよいかの確認、方針の選択、不足情報の確認など）は、**すべて `AskUserQuestion` を使うこと**。最終報告や途中経過の本文に質問を書いて、ターンを終えない。

- 報告と質問が同じターンにある場合は、報告を本文に書き、質問だけを `AskUserQuestion` で出す
- 1 回に最大 4 問までまとめる。推奨する案があれば先頭に置き、ラベルに「（推奨）」を付ける
- 各選択肢の description には、選んだ場合に何が起きるかを書く
- Codex では、利用できる質問ツールを使う。質問ツールが無い場合だけ、チャットで質問して回答を待つ

## なぜ

2026-10-26、`prune-tests` スキルの追加作業の最終報告で、「続けてコミットと PR 作成まで進めてよいか、fixture での評価も行うか、教えてください」と本文で質問してターンを終えた。ユーザーから、質問はすべて `AskUserQuestion` で行うよう指示された。
